A Page With No Styles Inside It

There is no style block anywhere in this file. All the appearance comes from style.css, which sits beside this page in the repository.

Why this is better

With an internal style block, every page needs its own copy of the rules. Change a colour and you change it six times.

With one stylesheet, every page links to the same file. Change the colour once and the whole site changes.

Try it

Hover over any link on this page and watch the background shift. That comes from the a:hover rule in style.css.
