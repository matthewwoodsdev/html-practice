HTML Notes

Tags I've used so far, written in my own words.

Structure

  1. <!DOCTYPE html> tells the browser this is a modern HTML page.
  2. <head> holds information about the page.
  3. <body> holds everything you actually see.

Content

  • <h1> to <h6> are headings, biggest to smallest.
  • <p> is a paragraph.
  • <a href="..."> is a link.
  • <hr> draws a line. No closing tag.

Tables

  • <table> wraps the whole thing.
  • <tr> is one row.
  • <th> is a heading cell, <td> is a normal cell.
